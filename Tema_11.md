## Лабораторная работа №2

Класс итератор с гибкой настройкой и удобными применением

```python
class CountDown:
    def __init__(self, start):
        self.count = start + 1
    def __iter__(self):
        return self
    def __next__(self):
        self.count -= 1
        if self.count < 0:
            raise StopIteration
        return self.count

if __name__ == '__main__':
    counter = CountDown(5)
    for i in counter:
        print(i)
```
### Результат.

![image](https://github.com/GanievaAnastasiia/Software_Engineering/blob/Тема_11/images11/2.png)

## Выводы

1. Класс CountDown предназначен для создания обратного отсчета от заданного числа до нуля.
2. __init__(self, start) метод является конструктором класса. Он принимает одно значение start, которое указывает начальное число для отсчета. Внутри метода создается переменная экземпляра self.count, которая инициализируется значением start + 1. Это сделано потому что при вызове метода next() сразу произойдет уменьшение значения счетчика на единицу.
3. Метод iter(self) возвращает объект, чтобы он мог использоваться в цикле for.
4. Метод next(self) выполняет интерации в циклах. При каждом вызове он уменьшает значение self.count на единицу. Если значение становится меньше нуля, генерируется исключение StopIteration, что сигнализирует о завершении цикла. В противном случае возвращается текущее значение count.

print('a - ', a)

## Лабораторная работа №5

Такой же счетчик, как и в первом задании, только это генератор и использует yield

```python
def countdown(count):
    while count >= 0:
        yield count
        count -= 1
if __name__ == '__main__':
    counter = countdown(5)
    for i in counter:
        print(i)
```
### Результат.

![image](https://github.com/GanievaAnastasiia/Software_Engineering/blob/Тема_11/images11/5.png)

## Выводы

1. countdown объявляет генератор, в цикле while будет вызывать yield, пока count не станет меньше 0.
2. В цикл for передается генератор counter:
   - count равен 5, и выводится 5.
   - count уменьшается на 1 и становится 4 тогда выводится 4.
   - это продолжается пока count не достигнет 0, которое будет выведено.
3. Когда count станет равным -1 цикл завершится.
