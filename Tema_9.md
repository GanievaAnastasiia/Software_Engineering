## Лабораторная работа №2

Вам дали важное задание, написать продавцу мороженого программу, которая будет писать добавили ли топпинг в мороженое и цену после возможного изменения. Для этого вам нужно написать класс, в котором будет определяться изменили ли состав мороженого или нет. В этом классе реализуйте метод, выводящий на печать «Мороженое с {ТОППИНГ}» в случае наличия добавки, а иначе отобразится следующая фраза: «Обычное мороженое». При этом программа должна воспринимать как топпинг только атрибуты типа string.

```python
class Icecream:
    def __init__(self, ingredient=None):
        if isinstance(ingredient, str):
            self.ingredient = ingredient
        else:
            self.ingredient = None
    def composition(self):
        if self.ingredient:
            print(f"Мороженое с {self.ingredient}")
        else:
            print('Обычное мороженное')
icecream = Icecream()
icecream.composition()
icecream = Icecream('шоколадом')
icecream.composition()
icecream = Icecream(5)
icecream.composition()
```

1. В классе  `Icecream` определён метод `init`. Если аргумент `ingredient` является строкой, то он сохраняется в атрибуте `self.ingredient`. В противном случае в `self.ingredient` устанавливается в `None`.
2. Метод `composition` проверяет, есть ли в объекте действительный ингредиент. Если да, выводится сообщение с указанием ингредиента, если нет тогда выводится `"Обычное мороженное"`.
3. Создаётся новый объект `icecream` с ингредиентом `шоколадом`. 
5. Создание объекта с неправильным ингредиентом: объект `icecream` с ингредиентом 5. Метод инициализации устанавливает `self.ingredient` в `None`, потому что 5 не является строкой. Метод `composition` выводит `"Обычное мороженное"`.


## Лабораторная работа №3

Петя – начинающий программист и на занятиях ему сказали реализовать икапсу…что-то. А вы хороший друг Пети и ко всему прочему прекрасно знаете, что икапсу…что-то – это инкапсуляция, поэтому решаете помочь вашему другу с написанием класса с инкапсуляцией. Ваш класс будет не просто инкапсуляцией, а классом с сеттером, геттером и деструктором. После написания класса вам необходимо продемонстрировать что все написанные вами функции работают.

```python
class MyClass:
    def __init__(self, value):
        self._value = value

    def set_value(self, value):
        self._value = value

    def get_value(self):
        return self._value

    def del_value(self):
        del self._value

    value = property(get_value, set_value, del_value, "Свойство value")

obj = MyClass(42)
print(obj.get_value())
obj.value = 45
print(obj.get_value())
obj.value = 100
print(obj.get_value())
obj.del_value() 
```
### Результат.
![image](https://github.com/GanievaAnastasiia/Software_Engineering/blob/Тема_9/images9/3.png)

## Выводы

1. Определение класса `MyClass`:
   - Определены три метода:
     - `set_value`: устанавливает значение атрибута `_value`.
     - `get_value`: возвращает текущее значение атрибута `_value`.
     - `del_value`: удаляет атрибут `_value`.
2. Свойство value использует методы `get_value`, `set_value` и `del_value`. 
3. Создаётся объект `obj` класса `MyClass` с начальным значением 42.
4. Использование сеттера: используется свойство value для установки значения 45; `get_value` возращает 45 и выводит это значение. (С значением 100 происходит аналогичная процедура)
5. Метод `del_value` нужен для удаления `_value`. 

- Почему возникла ошибка? Из-за неправильного использования свойства: Методы set_value() и del_value() должны вызываться через свойство value, а не напрямую. Например, для установки значения используется obj.value = 45, а не set_value(45).

Вам прекрасно известно, что кошки и собаки являются млекопитающими, но компьютер этого не понимает, поэтому вам нужно написать три класса: Кошки, Собаки, Млекопитающие. И при помощи “наследования” объяснить компьютеру что кошки и собаки – это млекопитающие. Также добавьте какой-нибудь свой атрибут для кошек и собак, чтобы показать, что они чем-то отличаются друг от друга.

```python
class Mammal:
    className = 'Mammal'

class Dog(Mammal):
    species = 'canine'
    sound = 'wow'
    
class Cat(Mammal):
    species = 'feline'
    sound = 'meow'

dog = Dog()
print (f"Dog is {dog.className}, but they say {dog.sound}")
cat = Cat()
print (f"Cat is {cat.className}, but they say {cat.sound}")
```

1. Класс Mammal содержит атрибут className 'Mammal'. Все подклассы этого класса будут иметь доступ к этому атрибуту.
2. Класс Dog наследует от класса Mammal. Он имеет все свойства и методы родительского класса. В классе Dog определены два атрибута: species и sound. Класс Cat ростроен аналогично.
3. Создаётся объект dog класса Dog. При вызове dog.className будет возвращено 'Mammal', так как класс Dog наследует этот атрибут от класса Mammal. При вызове dog.sound возвращается 'wow', так как этот атрибут определён в классе Dog. Тоже самое пооисходит и с Cat.

- Классы Dog и Cat наследуют от Mammal. Объекты этих классов имеют доступ к атрибутам родительского класса и своим собственным. В выоде для dog и cat можно увидеть принадлежность к классам и издаваемые звуки.

## Лабораторная работа №5

На разных языках здороваются по-разному, но суть остается одинаковой, люди друг с другом здороваются. Давайте вместе с вами реализуем программу с полиморфизмом, которая будет описывать всю суть первого предложения задачи. Для этого мы можем выбрать два языка, например, русский и английский и написать для них отдельные классы, в которых будет в виде атрибута слово, которым здороваются на этих языках. А также напишем функцию, которая будет выводить информацию о том, как на этих языках здороваются.
Заметьте, что для решения поставленной задачи мы использовали декоратор @staticmethod, поскольку нам не нужны обязательные параметры-ссылки вроде self.

```python
class Russian:
    @staticmethod
    def greeting():
        print("Приветик!")

class English:
    @staticmethod
    def greeting():
        print("Hello!")

def greet(language):
    language.greeting()
ivan = Russian()
greet(ivan)
John = English()
greet(John)
```
### Результат.

![image](https://github.com/GanievaAnastasiia/Software_Engineering/blob/Тема_9/images9/5.png)

## Выводы

1. Класс Russian содержит метод greeting(), который выводит строку "Приветик!". Аналогично для класса English. 
2. Функция greet принимает один аргумент language, который должен быть экземпляром класса с методом greeting.
3. Создаётся экземпляр класса Russian и присваивается переменной ivan.
4. Вызов функции greet с аргументом ivan приводит к вызову метода greeting() класса Russian, который выводит "Приветик!". Аналогичная ситация для класса English.

- В коде задействован полиморфизм. Оба класса реализуют метод greeting(), который вызывает функцию greet. Функция greet использует переданный аргумент для вызова соответствующего метода.
